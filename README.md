# solar_control — archived legacy repository

This repository is deprecated. Its reusable clear-sky-index climatology has
been migrated to the maintained
[`forecast_engine`](https://github.com/Laboratoire-Piment/forecast_engine)
package as `CSIClimatology`, `fit_csi_climatology`, and
`forecast_csi_climatology`.

Intentionally not migrated: the dynamic-programming solver, inverter
equations, battery dispatch example, grid-cost logic, duplicate solar
astronomy/Bird clear-sky implementation, plotting utilities, generated files,
and bundled data. Those are control, optimization, experiment, or obsolete
implementation concerns rather than reusable forecasting primitives.

The repository is retained read-only for historical provenance. No history
has been deleted.
